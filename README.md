# Credit Card Fraud Detection

This is my beginner-level machine learning project using Python in Google Colab.

## Dataset
I used the [Credit Card Fraud Detection dataset from Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).

## What I did
- Explored the dataset
- Checked missing values and duplicate records
- Preprocessed the data
- Trained Logistic Regression and Random Forest models
- Evaluated the models
- Compared both models using a graph

## Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
